## How to Run a C++ Program

1. Install a C++ compiler, such as **G++ (MinGW or GCC)**.
2. Open a terminal in the repository directory.
3. Compile a lab file:

```bash
g++ "Lab 10/Task 1.cpp" -o lab10-task1
```

4. Run the executable:

```bash
# Windows
lab10-task1.exe

# Linux/macOS
./lab10-task1
```
